Codeforces API

GET
/codeforces/<username>

Fetch competitive programming statistics including rating, rank, and solved problems from Codeforces.

Returns

  • Current rating
  • Maximum rating
  • Current rank
  • Total solved problems

Sample Response

{
  "curr_rating": 1600,
  "max_rating": 1800,
  "curr_rank": "expert",
  "max_rank": "candidate master",
  "problem_solved": 350
}
