CodeChef API

GET
url/codechef/<user_name>

Scrapes CodeChef user profile to extract rating, rating changes, and total solved problems.

Returns

  • Current rating
  • Rating change
  • Total problems solved

Sample Response

{
  "rating": "1800",
  "change_in_rating": "+50",
  "problems": "420"
}
